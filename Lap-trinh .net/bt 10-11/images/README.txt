HƯỚNG DẪN CHỤP ẢNH MÀN HÌNH NỘP BÀI:
1. Chạy ứng dụng MultiServiceEnterpriseSystem từ Visual Studio (F5).
2. Dùng tổ hợp phím [Windows + Shift + S] để chụp ảnh các màn hình thực tế:
   - 01_main_screen.png        : Màn hình Tổng quan Dashboard hệ thống
   - 02_crud_screen.png        : Màn hình Quản lý danh mục (CRUD Phòng hát, Dịch vụ, Phụ tùng)
   - 03_transaction_screen.png : Màn hình Thực thi nghiệp vụ Đặt phòng Karaoke & Lập hóa đơn Garage
   - 04_report_screen.png      : Màn hình Báo cáo - Thống kê doanh thu & Top dịch vụ bán chạy
   - 05_error_handling.png     : Màn hình Minh họa phòng chống SQL Injection & Transaction Rollback
3. Lưu các file ảnh vào thư mục images/ với đúng tên file định dạng .png ở trên.
